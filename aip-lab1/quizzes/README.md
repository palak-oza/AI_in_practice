# End-of-lab quizzes

One quiz per lab, sat in the last ten minutes of the session. Twenty questions,
one mark each, open notes and open repo — everything is drawn from the lab you
have just done, not from the theory sessions.

**How to sit it.** Open the `.html` file in a browser. There is nothing to
install and nothing leaves your machine.

1. Type your name and roll number.
2. Answer all twenty. Multi-select questions are all-or-nothing.
3. Press **Finish**. You get a **submission code**.
4. Post the code where your instructor asked.

**Your score is not shown on the page.** That is deliberate: the page contains
no answer key at all, so there is nothing in it to read out of the source. We
go through the answers together once the codes are in, which is a better use of
the ten minutes than each of you reading a number alone.

Reloading and starting again produces a code that says so.
