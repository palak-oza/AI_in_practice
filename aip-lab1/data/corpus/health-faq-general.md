# Frequently Asked Questions

A customer-facing summary. Where this FAQ and a plan document disagree, the
plan document governs. Several answers here are deliberately approximate.

**How soon can I claim after buying the policy?**
After 30 days for illness, immediately for accident. Some conditions wait longer.

**What is a waiting period?**
A period of continuous cover that must pass before certain claims become
payable. See `pre-existing-conditions` for the schedule.

**Is my treatment covered abroad?**
Generally no. One plan tier has a limited international emergency benefit.

**Do I need to inform you before going to hospital?**
Yes, for planned admissions. Timelines differ between cashless and
reimbursement and between product lines. See `claims-timelines`.

**How long does settlement take?**
Cashless is settled at discharge. Reimbursement takes up to a few weeks from
the last document.

**Can I add my parents?**
On some plans. See `dependents-and-family-floater`.

**What if I miss my renewal date?**
There is a grace period. Cover does not run during it. See
`policy-renewal-and-portability`.

**Is dental covered?**
Not in the base plan. There is an optional rider.

**Is maternity covered?**
On some plans, after a waiting period. See `maternity-benefits`.

**What if you reject my claim?**
There is a three-stage grievance process ending with the Ombudsman. See
`grievance-redressal`.
